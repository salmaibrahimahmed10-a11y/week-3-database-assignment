\# School Management Database



\## Project Description

This project demonstrates the creation and management of a School Management Database using MySQL.



\## Database Name

school\_management



\## Table Created

\*\*students\*\*



The students table contains:

\- student\_id

\- first\_name

\- last\_name

\- email

\- age

\- enrollment\_date



\## SQL Operations

The project demonstrates the following SQL commands:



1\. CREATE DATABASE

2\. USE DATABASE

3\. CREATE TABLE

4\. INSERT INTO

5\. SELECT
